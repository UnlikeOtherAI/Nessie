# Archived: native React Native mobile app

This is the original Expo/React Native mobile app with hand-built native
screens (login, channels list, channel view). It was superseded by a thin
WebView shell (`/mobile`) that loads the admin web UI directly, mirroring the
desktop Tauri app — the native screens diverged from the admin design system
and were not worth maintaining in parallel.

Kept for reference only. Not a pnpm workspace member; not built or shipped.
